# PageForge PDF Studio

Windows 和 macOS 客户软件发布仓库。请到 [Releases](https://github.com/smallannsen-droid/20231105/releases) 下载对应版本。

- **Windows v2.0.5**：Windows 10/11 x64。ZIP 同时包含正式安装器和可直接运行的便携目录。缺少 WebView2 时，安装器将调用微软官方引导程序安装。
- **M 系列 Mac v2.0.5**：macOS 15 或更新，ARM64 原生 App。默认使用系统原样预览，可在页面上方切换标准预览进行对比。ZIP 包含固定安装到 `/Applications/PageForge.app` 的 PKG 安装器及便携 App 压缩包，无需 Python。已在 macOS 15、26 验证安装后预览、编辑及退出。
- **离线字体包**：内置 31 个 Noto 开源字体家族、60 个字面，覆盖中日韩、常用西文及多种文字体系，相关 OFL 许可证随软件提供。
- **字体库与导入**：顶部“字体库”支持查看、搜索和导入本机 TTF / OTF / TTC / OTC 字体；编辑文字时可选择具体字体。导入内容仅保存在本机。
- **Meiryo UI**：支持识别已安装或导入的 Meiryo UI，区分字体集合中的常规、粗体等字面。本包不分发 Meiryo UI 字体文件；Windows 可读取系统已安装字体，Mac 可导入有权在本机使用的字体文件。
- **PDF 原样文字替换**：默认勾选“保持原字体与位置”，复用 PDF 内原字体资源、字号、颜色和基线。文字长度变化时沿原基线排字。原嵌入字体缺字或绘制方式暂不支持时，保留原文并提示；取消勾选可重新排版或改字体。图片处理保持原有方式。
- **语言切换**：顶部始终显示「中文 / 日本語 / English」三个按钮，点击切换并记住选择；顶部同时显示版本号。中、日、英文使用说明随包提供。
- 界面支持中文、日文、英文；主要功能包括页面整理、文字编辑、批注、图片移动缩放、导出转换、水印、页码、书签、密码保护和撤销重做。

压缩包解压信息由提供方单独告知。本仓库不公开项目源码、客户样本 PDF 或解压凭据。

macOS 包使用本地代码签名，未做 Apple Developer ID 签名和公证，首次安装或打开可能需要系统手动确认。

当前 Windows 和 M 系列 Mac 更新包附带验证记录。历史 Intel Mac 版本可在 Releases 中查找。具体使用说明和第三方许可随软件提供。
